Airgap is a **mode**, not a radio product and not Node Gate.

## Lock

**Airgap** = local vault + no bearer radios + no climb-back onto pulled
public hub hostnames.

A MirageGrid / AZ Generator node in airgap mode keeps the **full
verified Aziel Eliab paper set** as a **cold vault copy** on the node
(see AZ-GENERATOR-1.0 paper-vault-on-node). It does not climb back onto
pulled official-hub hostnames. It does not turn bearer radios on to
“stay alive.”

Official hubs (azieleliab.com, azielcorpuslibrary.net, godlock.uk,
hedidntjump.com) are **not** airgap Node Gate. They are not Node Gate
at all (MIRAGE-GRID-SHIFT-1.0).

## Downloads stay up

Downloads / serve from the **local cold shelf** are still allowed while
airgapped. Sites stay up for downloads when the origin node is offline
(already locked: COLD-COPY / MESH-VAULT snapshot+standby). Airgap does
not take the download plane down.

The download plane stays **pull-only**. Sender fan-out of bodies is
refused.

## Tip chatter when airgapped

If any tip chatter exists while airgapped, it is **live / locked /
isolated / tip-hash only**. No body gossip. No paper bytes on the 1s
tip tick. SPLIT THE WIRES is not rewritten: the tip plane stays
presence + tip-hash only.

## Re-expand / reheal when airgapped

Same REHEAL-1.0 / MESH-REHEAL law, tightened to bytes already trusted:

1. Own tip + trusted pull of **bytes already trusted**, or
2. phoenix-WAIT

Never neighbor majority. Never vote-to-fix. Never invent a paper set.
Incomplete vault → AZG-INCOMPLETE-VAULT / AZG-UNVERIFIED-TIP;
phoenix-WAIT; do not invent.

## Paper vault (cite)

“All Aziel papers pushed to each node” means **vault multiply onto
each node** / **papers land on every node as cold copies** — on
bootstrap / join / Cap-7 claim / grid-shift standby. Pull-only payload
plane, or vault-on-transfer multiply. **No live body sync / sender
fan-out of paper bytes on the 1s tick.**

Hash-absolute: each paper verifies by published tip/hash. Cite, don’t
merge. NO-FAN: no falsified paper set, no “we have 49” without bytes.
